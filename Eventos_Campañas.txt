# Eventos y Campañas

Registro de ferias, eventos del sector, webinars propios, lanzamientos de producto y
campañas comerciales activas que condicionan el calendario editorial de LinkedIn.

Este archivo lo alimentan:
- El agente-archivista, al clasificar entradas de INBOX.md relacionadas con eventos/campañas.
- El agente-investigador, al detectar ferias o hitos normativos con fecha durante su
  investigación autónoma mensual.

Formato de cada entrada (mantener este formato para que el agente-calendario y el
agente-investigador puedan parsearlo sin ambigüedad):

## [Nombre del evento/campaña]
- Tipo: Feria / Webinar propio / Lanzamiento de producto / Cambio normativo con fecha / Campaña comercial
- Fecha(s): dd/mm/aaaa (o rango)
- Relevancia: qué perfiles debería tocar y por qué (p. ej. "Enrique y Emma — autoridad en eventos/normativa")
- Estado: Activo / Pasado / Confirmado / Tentativo
- Fuente: de dónde sale el dato (INBOX, investigación web, briefing histórico)
- Notas: cualquier condicionante para el calendario (escasez de plazas, ponentes confirmados, etc.)
